# 堤防安全评价指标量化方法说明

## 1. 为什么定性指标可以映射为分数

规范和导则通常给出的是安全状态描述、控制要求或评价等级含义，并不一定直接给出“某项指标等于多少分”。因此，本文的指标量化不应表述为“规范直接给分”，而应表述为：

> 依据规范控制值、导则评价语义、工程地质勘察结论和历史险情资料，建立指标评分锚点，将定量指标和定性指标统一转换为 0-100 分的无量纲评价值。

其中：

- 定量指标：由规范控制值或计算结果建立连续评分函数。
- 定性指标：由导则状态描述或工程资料分档，采用评分锚点映射。
- 缺失指标：不默认满分，暂不参与本次评价，待使用方补充后纳入。

## 2. 分数锚点的含义

建议在论文中统一说明以下评分语义：

| 分值 | 安全语义 | 适用情况 |
|---:|---|---|
| 100 | 满足要求且状态良好 | 规范达标、无明显隐患、资料显示状态良好 |
| 80 | 基本良好 | 定性资料显示轻微缺陷，但不影响主要安全功能 |
| 70 | 一般或轻微风险 | 有轻微病害、已加固、局部问题但未形成明显危险 |
| 60 | 临界可接受或基本满足 | 刚达到基本要求，或存在一般隐患 |
| 40 | 明显缺陷 | 存在明显病害，需要关注或处置 |
| 20 | 接近危险状态 | 定量指标接近失稳或严重不满足 |
| 0 | 严重不满足或失效 | 关键指标失效、严重超限、未处理重大险情 |

这不是规范原文给分，而是将规范/导则的等级语义转换为统一评分尺度。

## 3. 定量指标的量化

### 3.1 几何与防洪硬指标

这些指标有明确控制要求，适合采用 0/100 二值评分：

| 指标 | 代码 | 量化规则 |
|---|---|---|
| 堤顶宽度、外坡坡比、内坡坡比 | A1 | 全部满足设计标准为 100，否则 0 |
| 堤顶高程/超高 | B1 | 堤顶高程 ≥ 设计洪水位 + 安全超高为 100，否则 0 |
| 软基沉降与沉降差 | A5 | 沉降量、沉降差均不超过允许值为 100，否则 0 |

论文表述：

> 对具有明确规范控制值的指标，采用达标判别法进行量化。满足规范要求赋 100 分，不满足要求赋 0 分，并在后续物理门控中限制评价等级。

### 3.2 渗流稳定指标

渗流类指标采用 Terzaghi 临界水力梯度理论进行连续评分。对具有比重
`Gs` 和孔隙比 `e` 的控制土层，临界水力梯度取：

代码中采用：

```text
i_cr = (Gs - 1) / (1 + e)
R = i / i_cr
S = 100 * (1 - R^2), 0 <= S <= 100
```

其中 `i_cr` 为 Terzaghi 临界水力梯度，`i` 为 GeoStudio 或渗流计算得到的实际水力梯度，
`R` 为接近临界状态的风险比。当 `R >= 1.0` 时，认为达到渗流破坏临界状态，
物理门控直接判为 C 级不安全；当 `R` 越接近 0，渗流安全裕度越充足。

| R 范围 | 工程含义 | 得分 |
|---:|---|---:|
| R = 0 | 无明显渗透坡降风险 | 100 |
| 0 < R < 1.0 | 随接近临界状态连续降低 | `100 * (1 - R^2)` |
| R ≥ 1.0 | 达到或超过临界水力梯度 | 0，并触发物理门控 |

对应指标：

| 指标 | 代码 | 含义 |
|---|---|---|
| 堤基渗透比降 | C1 | `i_base / i_cr_base` |
| 堤身渗流稳定 | C4 | `i_body / i_cr_body` |
| 接触面渗透/冲刷安全 | C5 | `i_contact / i_cr_contact` |

论文表述：

> 对渗流稳定指标，本文基于 Terzaghi 临界水力梯度理论确定渗透破坏临界值，
> 以实际水力梯度与临界水力梯度的比值作为风险比，并采用连续衰减函数将其转换为
> 0-100 分评价值。当实际水力梯度达到临界水力梯度时，判定渗流稳定性不满足要求。

### 3.3 抗滑稳定指标

抗滑稳定指标采用安全系数连续评分。

背水坡稳定安全系数 `D1`：

| FoS 范围 | 工程含义 | 得分 |
|---:|---|---:|
| FoS ≥ 1.50 | 安全裕度充足 | 100 |
| 1.35 ≤ FoS < 1.50 | 满足规范 | 75-100 线性 |
| 1.00 ≤ FoS < 1.35 | 不满足规范但未临界 | 20-75 线性 |
| FoS < 1.00 | 失稳 | 0 |

临水坡稳定安全系数 `D2`：

| FoS 范围 | 工程含义 | 得分 |
|---:|---|---:|
| FoS ≥ 1.40 | 安全裕度充足 | 100 |
| 1.25 ≤ FoS < 1.40 | 满足规范 | 75-100 线性 |
| 1.00 ≤ FoS < 1.25 | 不满足规范但未临界 | 20-75 线性 |
| FoS < 1.00 | 失稳 | 0 |

论文表述：

> 对抗滑稳定安全系数，首先以规范允许值作为达标边界，以 FoS=1.0 作为极限平衡临界边界；当 FoS<1.0 时评分为 0，当 1.0≤FoS<FoS_allow 时按未达标但未临界状态线性评分。

## 4. 定性指标的量化

定性指标不能声称由规范直接给出分数，应写成“基于导则评价语义的分档赋值”。

### 4.1 地质和工程质量类指标

| 指标 | 代码 | 量化依据 | 评分规则 |
|---|---|---|---|
| 填土质量 | A2 | 地勘报告定性结论 | 质量较好 100；质量一般 80；质量较差 60 |
| 穿堤建筑物检测结论 | A3 | 检测/处置结论 | 加固 100；改建 70；重建 0 |
| 堤身内部隐患 | A6 | 地勘资料或后续使用方资料 | 无明显隐患 100；已处理轻微隐患 70；未处理蚁穴堤或明显隐患 40 |
| 堤基不良地质体基础状态 | A7 | 地勘资料或后续使用方资料 | 一般地基 100；C 类地基 70；D 类地基 60；若有处理质量资料则按实际输入覆盖 |
| 护坡完好率 | A4 | 后续使用方资料 | 优 100；良 80；中 60；差 40；极差 0 |

### 4.2 渗漏、冲刷和历史险情指标

| 指标 | 代码 | 量化依据 | 评分规则 |
|---|---|---|---|
| 管涌与渗漏观测证据 | C3 | 历史险情、人工巡查、无人机识别渗漏点 | 按加权渗漏点密度分档：0 点/100m 为 100；0-1 为 80；1-2 为 60；2-4 为 40；>4 为 0 |
| 冲刷与历史险情 | D3 | 冲刷深度、历史管涌/散浸/渗漏/崩岸记录 | 冲刷 ≥1.0m 或未加固重大险情 0；冲刷 0.5-1.0m 或已加固重大险情 70；无明显冲刷和险情 100 |
| 穿堤建筑物渗流稳定 | C6 | 后续使用方资料 | 无渗漏 100；明显渗漏 60；失稳 0 |

论文表述：

> 对渗漏、冲刷和历史险情等难以直接连续量化的指标，依据险情严重程度建立分档评分。分档评分的目的不是替代现场鉴定，而是将导则中的定性安全状态转化为云模型可处理的无量纲输入。

无人机巡检结果仅提供点状渗漏观测，不能直接反映渗漏面积、渗漏流量或渗透比降。因此本文不新增独立的“无人机检测指标”，而将无人机识别结果作为 C3“管涌与渗漏观测证据”的数据来源之一。加权渗漏点密度计算为：

```text
D = 100 × Σ(ci · wi · ri) / L
```

其中 `ci` 为识别置信度，`wi` 为位置敏感权重，`ri` 为重复出现权重，`L` 为评价段长度。普通单点渗漏仅影响 C3 得分；若渗漏点位于堤脚、穿堤建筑物、结合部或历史险情附近，或出现多点、重复、集中、带砂、冒水等特征，则进一步触发 UAV 观测证据门控，对最终安全等级设置上限。

为避免重复计分，蚁穴堤、堤身内部隐患归入 A6；管涌、散浸、渗漏、崩岸等渗流或岸坡破坏险情归入 D3。

### 4.3 运行管理类指标

这些指标目前在代码中设置为“待输入”，缺失时不参与本次评价。

| 指标 | 代码 | 推荐评分规则 |
|---|---|---|
| 监测设施完备性 | E1 | 完善 100；一般 80；差 40 |
| 管理制度健全性 | E2 | 健全 100；基本健全 70；不健全 40 |
| 维护记录完整性 | E3 | 完备 100；基本满足 70；缺失 0 |
| 应急预案与防汛物资 | E4 | 完备 100；基本满足 70；严重缺失 0 |
| 隐患巡查与处置率 | E5 | 全部处置 100；部分处置 60；未执行 0 |

论文表述：

> 对运行管理类指标，若缺少可靠资料，则不将其默认赋为满分，而是作为缺失指标暂不参与计算，并对有效指标权重进行归一化处理。

## 5. 为什么使用 0、60、70、80、100 这些分值

这些分值属于评分锚点，含义如下：

- 100：完全满足或状态良好；
- 80：基本良好，存在轻微缺陷；
- 70：一般状态或已处置轻微风险；
- 60：基本满足或临界可接受；
- 40：明显缺陷；
- 0：严重不满足或失效。

论文中应说明：

> 分值设置参考安全评价中常用的等级赋值思想，将“良好、一般、较差、严重”等定性描述映射到 0-100 评分尺度。对于关键失效模式，评分结果还需经过物理门控校核，避免加权平均掩盖单项严重风险。

## 6. 缺失指标处理

当前代码已经采用：

```text
缺失指标 = None
缺失指标不生成云滴
组内权重重新归一化
若某一级维度全部缺失，则该维度暂不参与一级聚合
```

这比默认 100 更严谨。

论文表述：

> 对尚未取得使用方资料的指标，本文不将其默认视为合格，而是作为缺失指标处理。计算时仅对已有可靠数据的指标进行聚合，并对有效权重进行归一化。

## 7. 最适合论文使用的总表述

> 本文将评价指标分为定量控制指标和定性状态指标两类。对于具有明确规范控制值的指标，如抗滑稳定安全系数、渗透比降、堤顶高程和断面尺寸等，依据规范限值构建达标判别或分段连续评分函数；对于填土质量、历史险情、渗漏现象、运行管理等定性指标，依据安全评价导则的状态描述、工程地质勘察资料和现场资料建立分档评分规则。所有指标统一转换为 0-100 分无量纲评价值，作为云模型输入。对于缺少可靠资料的指标，不进行默认赋值，而采用缺失处理和权重重归一化方法。
