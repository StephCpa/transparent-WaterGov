本目录保存875组合成样本和评价模型共用的指标体系、量化口径、权重推导及关联矩阵，是理解模型输入与权重来源的基础。

| 文件 | 用途 |
| --- | --- |
| `875样本模型测试资料包说明.md` | 说明875组样本的组成、29项指标的来源、PPT统计结果，以及整个资料包的目录结构。 |
| `参考等级生成规则.md` | 说明875组样本如何按“安全、轻微、中等、严重、临界”五档严重程度生成A级、B级、C级预设参考等级。 |
| failure_mode_indicator_matrix.csv | 29项指标与漫顶、渗流、边坡、冲刷、穿堤建筑物五类失效模式的关联强度表格版，适合直接用Excel查看。 |
| `failure_mode_indicator_matrix.json` | 与CSV内容对应的程序读取版关联矩阵；评价程序通过该文件读取指标名称、关联强度、运行管理屏障角色和关联依据。 |
| `indicator_quantification_method.md` | 29项指标的量化方法、评分锚点、主要计算公式及缺失值处理规则。用于说明原始指标如何统一换算为0--100分。 |
| `failure_mode_matrix_method.md` | 说明失效模式权重和模式内指标权重如何由导则综合权重与关联强度计算得到，并给出运行管理屏障和无人机渗漏证据的处理方法。 |

其中，`failure_mode_indicator_matrix.json` 是评价代码运行所需的配置文件；其余文件主要用于人工核对、论文写作和复现说明。
