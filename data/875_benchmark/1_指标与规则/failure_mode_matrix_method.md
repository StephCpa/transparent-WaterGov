# 失效模式-指标关联矩阵及权重推导方法

## 1. 建立目的

原始导则指标体系按照工程质量、防洪安全、渗流安全、结构安全、运行管理划分，适合检查项目是否完整，但不直接说明堤防会以何种方式失效。

因此，本方法在保留导则指标体系的基础上，引入失效模式层：

```text
导则指标层 -> 失效模式响应层 -> 安全屏障修正层 -> 综合风险度量
```

失效模式包括：

- 漫顶失效
- 渗流破坏
- 边坡失稳
- 冲刷破坏
- 穿堤建筑物失效

运行管理指标 E1-E5 不直接归入某一种物理失效模式，而是作为安全屏障层，用于修正物理失效风险。

## 2. 关联强度赋值

失效模式-指标关联矩阵采用 0-3 级赋值：

| 关联强度 | 含义 | 解释 |
|---:|---|---|
| 0 | 无直接关系 | 该指标不直接控制该失效模式 |
| 1 | 间接影响 | 该指标会通过其他过程影响该失效模式 |
| 2 | 重要影响 | 该指标对该失效模式有明显影响 |
| 3 | 直接控制 | 该指标是该失效模式的主要控制量或临界判据 |

例如，堤顶高程 B1 对漫顶失效为 3，因为堤顶高程与设计洪水位及超高要求直接决定漫顶风险；背水坡抗滑稳定系数 D1 对边坡失稳为 3，因为其本身就是边坡稳定的直接判据；堤基渗透比降 C1 对渗流破坏为 3，因为其与临界水力梯度直接相关。

## 3. 权重推导公式

设第 `i` 个指标的导则综合权重为 `w_i`，该指标对第 `j` 个失效模式的关联强度为 `r_ij`，则该指标对该失效模式的贡献为：

```text
q_ij = w_i * r_ij
```

第 `j` 个失效模式的权重为：

```text
W_j = sum(q_ij) / sum(sum(q_ij))
```

第 `j` 个失效模式内部，第 `i` 个指标的归一化权重为：

```text
beta_ij = q_ij / sum(q_ij)
```

因此，失效模式权重不是另行主观指定，而是由导则指标权重和破坏机理关联强度共同确定。

| 失效模式 | 权重 |

该结果符合长江中下游堤防评价的一般风险认识：渗流破坏和边坡失稳是主要控制失效模式，漫顶失效受防洪标准和堤顶高程控制，冲刷和穿堤建筑物失效为局部控制因素。

## 6. 定性指标无专家打分时的处理

对于缺少连续量测数据的定性指标，本研究不采用专家对具体工程打分，而采用规则锚定的状态分级法：

| 状态 | 建议赋值 | 含义 |
|---|---:|---|
| 完全满足、完好、无影响 | 100 | 功能完整，无明显风险 |
| 轻微缺陷、基本满足 | 70-80 | 功能基本保持，但存在轻微退化 |
| 一般、待复核、局部缺陷 | 60 | 功能存在不确定性，需要复核或维护 |
| 明显缺陷、功能降低 | 40 | 安全储备明显降低，但未达到完全失效 |
| 不满足、严重缺失、失效 | 0 | 失去相应功能或触发严重风险 |

这些分值不是专家对工程的主观评分，而是将导则中的状态性描述转换为统一量纲的状态编码。为避免单个赋值点过于主观，论文中应配套进行敏感性分析，例如将中间状态分值在 50-80 范围内扰动，观察安全等级和主控失效模式是否稳定。

## 7. 运行管理指标的验证方式

运行管理指标 E1-E5 不宜直接与物理指标同层加权，因为其作用不是改变堤体本身的强度，而是影响隐患发现、险情处置和风险扩展控制能力。

因此，本方法将 E1-E5 定义为安全屏障能力 `B_m`：

```text
r_j* = min(1, r_j + lambda * C_m * r_j * (1 - r_j) * (1 - B_m))
```

其中 `r_j` 为第 `j` 个失效模式的原始风险响应，`r_j*` 为运行管理屏障修正后的风险响应，`B_m` 为已输入运行管理指标的屏障能力，`C_m` 为运行管理信息覆盖度。该式表示：运行管理越薄弱，中等风险被放大的程度越明显；已经接近 0 的低风险和接近 1 的临界风险不会被过度扭曲。同时，若只输入少量运行管理指标，则通过 `C_m` 限制其修正强度，避免单个管理指标代表全部运行管理水平。

若有历史险情资料，可采用案例回放验证：

```text
历史破坏或险情案例 -> 提取物理指标 -> 输入运行管理状态 -> 比较有无屏障修正时的等级和主控模式
```

如果暂时没有足够历史样本，则运行管理层应作为情景分析或案例回放分析，而不宜写成统计意义上的验证。

## 8. 无人机渗漏点观测证据的处理

无人机巡检结果主要提供渗漏异常点的位置和出现情况，不能直接获得渗漏面积、渗漏流量或渗透比降。因此，本文不将无人机检测设置为独立新增指标，而是作为 C3“管涌与渗漏观测证据”的数据来源之一。

该处理有两个目的：

- 保持原有导则指标体系和 AHP 权重结构不变，避免新增指标后重新构造判断矩阵；
- 避免“无人机检测”和 C3 渗漏隐患重复计权。

无人机渗漏点首先通过加权渗漏点密度影响 C3 得分：

```text
D = 100 × Σ(ci · wi · ri) / L
```

其中 `ci` 为无人机识别置信度，`wi` 为位置敏感权重，`ri` 为重复出现权重，`L` 为评价段长度。根据 `D` 对 C3 分档赋值。

同时，为避免严重观测证据被综合评价平均掉，设置 UAV 观测证据门控：

| UAV证据等级 | 条件 | 处理 |
|---:|---|---|
| 0 | 未发现渗漏点 | 不修正 |
| 1 | 普通单点渗漏 | 仅进入 C3 评分 |
| 2 | 敏感位置、多点或重复出现 | 最终等级最高不超过 B 级 |
| 3 | 集中、重复严重、带砂、浑水或冒水 | 最终等级最高不超过 C 级，或触发 C 级复核 |

因此，无人机检测结果的作用不是改变指标权重，而是改变 C3 得分并在严重情况下触发观测证据门控。
