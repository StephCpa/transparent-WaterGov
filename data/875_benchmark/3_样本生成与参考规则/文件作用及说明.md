# 本目录文件说明

本目录是可独立运行的875组合成样本生成与评价程序。进入本目录后执行 `python synthetic_dataset_evaluation.py`，程序会按固定随机种子重新生成875组样本及其评价结果。

| 文件或目录 | 用途 |
| --- | --- |
| `synthetic_dataset_evaluation.py` | 主生成程序。按7类目标情景、5档严重程度、每种组合25次重复构造875组样本，生成预设场景数据后调用评价模型。 |
| `参考等级生成规则.md` | 说明样本严重程度与A级、B级、C级预设参考等级之间的映射关系。 |
| `failure_response_barrier_model.py` | 失效响应--安全屏障耦合模型。根据29项指标计算五类物理失效模式的风险响应，施加物理临界门控和运行管理屏障修正，输出最终等级和主控模式。 |
| `safety_evaluation.py` | 基础指标计算程序。负责29项指标量化、渗流和抗滑等物理计算、无人机渗漏证据处理及基础评分函数。 |
| `failure_mode_indicator_matrix.json` | 评价模型调用的29项指标--失效模式关联矩阵与运行管理屏障配置。 |
| `synthetic_dataset_outputs` | 运行主生成程序后自动生成的输出目录，包含875组输入样本、完整评价结果、汇总表和贡献率结果。该目录为可再生程序输出。 |

程序使用固定随机种子 `20260616`，因此在相同代码与依赖环境下重复运行可复现相同的875组样本及等级统计结果。
