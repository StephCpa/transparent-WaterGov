# K45+500 物理计算过程与历史一致性说明

## 1. 独立样本与最不利工况

K45+500 位于工程地质报告记载的 2017 年 K44+500—K46+096 管涌险情范围内。选取该桩号，是为了利用真实历史险情检验模型对主导风险模式的识别能力，而不是利用该险情重新拟合模型权重。

断面参数取堤顶高程 36.30 m、顶宽 7.0 m、背水坡 1:2.8、临水坡 1:2.7。堤基层序按资料范围取中值：表层粉细砂/砂壤土 2.6 m、下伏淤泥质粉质黏土 8.5 m、其下为砂砾石。资料仅给出层厚范围时采用中值，避免无依据地取极端值。

临水位取 35.90 m，构造接近堤顶的最不利稳定渗流工况，用于检验高水位条件下的渗流和边坡稳定响应。历史险情记录用于确认该段曾发生管涌；水位参数用于实施本次静力复算，两者不混淆。

## 2. 参数与公式

黏聚力、内摩擦角、重度、土粒比重、孔隙比和渗透系数均采用工程地质资料的建议参数，渗透系数由 cm/s 统一换算为 m/s。采用稳态有限差分法计算水头场与水力梯度，采用 Bishop 简化法进行边坡稳定复核。

渗流稳定采用 Terzaghi 临界水力梯度：

`i_cr=(Gs-1)/(1+e)`

实际风险比为 `R=i/i_cr`。对各土层分别计算最大坡降和临界坡降，取 `R` 最大者为控制层。

## 3. 计算结果

| 土层 | 最大坡降 i | 临界坡降 i_cr | i/i_cr |
| --- | ---: | ---: | ---: |
| 堤身填土 | 0.535 | 0.956 | 0.560 |
| 粉细砂/砂壤土 | 0.398 | 0.971 | 0.410 |
| 淤泥质粉质黏土 | 0.865 | 0.827 | 1.045 |
| 砂砾石 | 0.256 | 1.138 | 0.225 |

控制层为淤泥质粉质黏土，其 `i/i_cr=1.045`，达到渗透破坏临界。背水坡 FoS 为 1.155，小于正常运用允许值 1.35；临水坡 FoS 为 2.063，大于允许值 1.25。

## 4. 模型输出与验证判断

将实算的 C1、C4、C5、D1、D2 输入原模型，并将历史已确认管涌状态映射为 C3=0。穿堤建筑物、跨堤工程等本断面不涉及的指标不纳入相应评价；运行管理项不施加屏障修正。模型输出为：安全得分 24.3481、**C级不安全**、主控失效模式为 **渗流破坏**。C1 达到临界是直接门控原因，背水坡稳定不足为共同不利因素。

计算结论与 2017 年该范围发生管涌并采取导滤围井处置的历史事实一致。因此，本案例验证了模型在已有断面和地勘参数、高水位工况下对“渗流主控高风险状态”的识别能力。
