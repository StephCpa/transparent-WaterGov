## 2. 小论文定位、题目与研究问题

推荐题目：**《融合渗流机理与巡检证据的堤防渗流安全透明评价方法》**。

备选题目：**《考虑多源信息不确定性的堤防渗流安全动态评价方法》**。

待获得实际平台联动证据后，可使用“……及数字孪生验证”副题；平台展示本身不作为评价方法有效性的主要证据。

目标读者为水利工程、岩土工程与工程安全评价研究者。核心目标是检验：**在同一堤段和工况下，融合具有物理含义的渗流验算量与可信巡检证据，是否能减少危险状态低估，并使结论的来源和不确定性可追溯。**

首篇范围限定为土质堤防堤身/堤基渗流稳定。大坝与边坡只作为后续适用性讨论；漫顶、河岸冲刷、一般抗滑稳定不纳入本篇综合评分。若分析“渗流诱发边坡失稳”，必须另有稳定计算和强度参数支持。

三个研究问题：

- RQ1：地质模型、渗流场、巡检观测的空间尺度和时间尺度不同，如何统一为可比较、可追溯的评价证据？
- RQ2：当平均评分与局部关键险情冲突，或计算与现场观测不一致时，如何形成有物理约束的评价，而不把严重异常平均掉？
- RQ3：输入不确定、巡检不完整和观测过期时，如何量化评价结论的稳定性并动态更新？

拟检验假设：H1，关键物理约束可降低危险等级被低估的比例；H2，巡检融合可改善仅依赖计算时对实测异常的响应，但误报率需同步评估；H3，不确定性传播能够识别等级边界附近的不稳定结论，而非给出虚假的确定分数。上述均为待检验假设。

### 4.2 评价单元与配准

- 采用“堤段 × 代表断面/重点区域 × 工况/时刻”。分段依据为地层变化、结构变化、钻孔控制程度、潜在出逸区域和巡检覆盖。
- 初步可比较25、50、100 m三种沿堤长度，均为待检验空间尺度，不是规范要求。局部异常应保留点/面级记录，不随单元平均而消失。
- 统一坐标与高程基准。无人机经纬度到堤防桩号/局部坐标的变换应保留误差；仅有图像而无可靠定位时，先建立人工确认映射表。
- 区分采集时间、入库时间、计算有效时间。按采集时间关联工况，限定允许时间差和水位变化范围，阈值根据数据频率确定。
- 边界附近事件可带位置区间关联多个候选单元，但不得复制成多个独立险情样本。
- 同一渗漏点的视频连续帧合并为事件；不同架次重复观测用于持续性判断，不作为独立真实险情数量。

## 5. 指标体系：先建小而完整的证据链

建议先建立8—12个候选核心变量，再依据数据可得性和冗余检查收敛。地质、水位、计算、巡检均保留来源，但不要求每个来源都直接进入同一个加权和。

| 类别 | 候选变量 | 物理/观测含义 | 如何使用 |
|---|---|---|---|
| 地质 | 覆盖层厚度与完整性 | 承压逸出与薄弱区背景 | 选择破坏场景，参与计算；若作用已反映在物理指标内，不再重复独立加分 |
| 地质 | 透水层连通特征、层间接触与局部缺陷 | 可能的渗流/侵蚀路径 | 场景适用性、薄弱部位解释 |
| 地质 | 土体级配、抗渗/抗蚀能力、反滤条件 | 不同渗透破坏的抗力条件 | 决定指标和阈值适用范围 |
| 物理 | 出逸梯度/允许梯度 | 出口渗流作用裕度 | 核心指标与约束；固定取值区域，检查网格敏感性 |
| 物理 | 盖层抗浮或抗隆起裕度 | 承压作用与盖层抗力关系 | 对适用盖层结构单独验算，不与管涌判据混为一谈 |
| 物理 | 浸润线/渗出点位置 | 渗流外露部位与范围 | 与现场位置相互核对 |
| 物理 | 渗流量/孔压的异常或变化 | 荷载和模型偏差的响应 | 有监测时结合残差分析，不把任一大值直接定为危险 |
| 巡检 | 可信异常事件及空间范围 | 表面渗漏疑似证据 | 框检测仅用于定位；定量面积需分割或人工测绘 |
| 巡检 | 异常持续性/增长性 | 状态变化 | 需要多时相可比观测，按事件去重 |
| 巡检 | 现场出砂、浑水、隆起等复核 | 侵蚀或变形证据 | 与疑似热异常分层，参与等级下限约束 |
| 工况 | 水位差、高水位持续时间、涨落过程 | 水力荷载历史 | 主要驱动渗流求解及时间匹配，避免再次重复计权 |

对关键指标建立“数据字段—计算表达式—单位—适用机制—阈值来源—关联单元—证据来源”字典。阈值来源按现行规范/工程验算、土工试验、独立校准数据、专家依据分开记录。

特别说明：饱和无黏性土向上渗流条件下常用的理论临界梯度关系有其适用条件，不能将单一临界梯度公式推广成全部管涌、接触冲刷和集中渗漏的统一判据。不同侵蚀机制应选择适用试验或模型。

## 6. 推荐评价模型

### 6.1 研究模型的组成

采用“规范/物理依据量化＋失效场景组织＋多源证据融合＋关键条件约束＋不确定性传播”。以现有PPT为起点，先完成可解释、参数量有限的版本，再检验复杂模块是否确有增益。

渗流场景暂定为：堤基出口及覆盖层失稳；与土体侵蚀相关的内部渗透破坏；存在明确接触带或结构缺陷时的集中渗漏。场景可能关联或共同发生，不把这些输出当作互斥事件概率。资料不足时仅保留能够验算和验证的场景，不强行凑齐模式数量。

### 6.2 指标量化与组合赋权

将各指标通过有方向、有锚点的函数映射到[0,1]不利响应r_i。锚点优先来自规范/试验/工程适用条件。不同批次不采用各自min-max重新缩放，否则同一工程状态会因样本变化得到不同等级。

为满足第6章“组合赋权”的安排，可比较：

- 基准：有依据的固定权重或AHP权重，公开判断矩阵与一致性检验；
- 候选：w_i = η·w_i^AHP + (1−η)·w_i^CRITIC，η在校准资料上确定；
- 客观赋权只能使用开发集中的有效独立单元；大量相邻帧、网格节点和人工组合情景不构成充分的独立样本。

规范若没有给出数值权重，不得称自设权重为“规范权重”。CRITIC反映离散与相关结构，不等于物理重要性；对噪声与高度相关的变量做剔除、合并或组内限额。若组合赋权收益不足，保留简单权重模型并如实报告。

### 6.3 模式内响应与防止重复计分

为场景m定义适用指标集合I_m和关联系数a_im；得到：

β_im = w_i a_im / Σ(k∈I_m) w_k a_km；

B_m = Σ(i∈I_m) β_im r_i。

关联系数先以有明确依据的0/1适用关系作为简化基准；若沿用PPT的0/1/2/3，需说明等级定义、专家分歧和结果敏感性。分母为零说明场景缺少可用指标，应输出“证据不足”。

每个原始证据分配唯一ID。来自同一渗漏事件的热异常、检测置信度、连续帧计数不能作为相互独立的三份证据；来自同一渗流模型的水头、孔压和梯度也要检查相关与派生关系。场景层加权应公开展开后的有效指标权重，检查重复关联是否放大某类输入。

### 6.4 物理约束与巡检证据约束

推荐候选表达为：

R_m = max(B_m, L_m^phys, L_m^obs)。

其中L为证据触发后的不利响应下限，规则在开发/校准阶段确定，不事后按测试标签调整。该式是待验证的研究规则，不是现行规范规定。

- L_m^phys：来自适用物理验算是否满足要求及其不确定性。达到设计限值表示特定验算不满足或裕度不足，不自动等于已经发生破坏。
- L_m^obs：分为疑似视觉/热异常、重复观测确认、现场独立复核等层次。仅有低可信异常时进入待复核状态；有明确现场侵蚀证据时，综合平均值不能把该证据覆盖掉。
- 同一巡检量如果已进入B_m，再用于下限约束，应明确是同一证据的非补偿规则，不把它计为额外独立证据或再次加分。
- 质量差/观测过期时，扩大区间或标记证据不足，不能简单乘小置信度后把危险程度变低；未观测到异常与完成有效巡检后确认无异常需要区分。
- 计算预测低不利、观测显示异常时：保留冲突，触发核查定位、边界和参数；不得自动认定观测错误或把模型直接调到一致。
- 观测衰减只表示当前证据时效下降，已确认且未复核消除的险情不能自动随时间衰减为安全。

模式级结果优先展示。为兼容PPT，可将ρ = α max_m R_m + (1−α)Σ_m W_m R_m作为辅助综合指数，W_m≥0且总和为1。物理/现场触发的等级约束直接作用于最终类别，不能被α的选择再次稀释。通过消融检验该综合指数是否比直接报告模式结果有额外作用。

ρ、R_m均为评价指数，不是失事概率；不把1−ρ称为可靠度。

### 6.5 分级与不确定性

并列输出两类信息：一类是按适用条文形成的渗流分项验算结论；另一类是研究用的动态状态分级。研究状态可暂用“常态、关注、警戒、高度关注”等工作标签，最终命名、阈值和应对含义需与工程方对应。若采用PPT的A/B/C，应明确其究竟对应规范分项结论还是自定义研究类别，不与工程综合安全类别直接等同。

状态阈值由适用规范、物理裕度和独立校准资料共同确定，并在测试前固定。不预设“80分安全”等无来源数值。

不确定性分别处理：

- 地质结构：允许层界变化、多种合理结构，保持层序和厚度约束；
- 参数：有试验样本时拟合或重采样，有范围时做区间情景分析；
- 观测：位置误差、误检、覆盖和时效；
- 评价规则：权重、阈值和关联强度变化。

保留参数间和空间相关性，不对所有参数随意独立采样。对有概率依据的抽样结果，可报告评价指数分位区间与各等级的抽样占比；没有概率依据时只能报告情景范围，不能命名为95%置信区间。无论哪种情况，等级占比都不等于工程失事概率。

先用低成本断面开展试算，再按输出分位数、等级占比或排序的收敛程度增加抽样量。可将200、500、1000次作为计算预算比较点，而非默认充分的样本量。若采用代理模型降低成本，必须在独立样本上检验临界区误差。

### 6.6 动态更新和透明输出

触发条件：新水位/工况、新巡检事件、独立复核、新地勘或参数版本。更新流程为对齐证据→必要时重算渗流→更新指标→评价→保存依据→回传平台。

首版可以完成多稳态工况的评价刷新和历史回放。只有获得经验证的非稳态求解器、储水/非饱和参数及水位过程后，才开展真正的洪水过程渗流演化与提前量验证。快速更换稳态水位不是瞬态渗流模拟。

每个单元输出：模式响应、研究状态、物理验算结论、不确定性范围、数据充分性、主控指标、约束触发原因、证据索引、有效时间、模型与规则版本。线性部分可以直接报告β_im r_i的贡献；max约束部分应显示触发的约束及其影响，不能用线性贡献率解释全部最终输出。

“透明评价”的操作定义是数据来源可查、计算/规则可复核、结论原因可解释、版本变化可回放，并检验这些属性是否在实际案例中实现。

## 7. 验证方案

### 7.1 三层证据

| 层次 | 内容 | 可支持的结论 |
|---|---|---|
| 方法规则与合成情景 | 关键量单调性、极值、短板、缺测、证据冲突、去重、重复计分检查 | 实现正确性与规则行为，不证明工程预测精度 |
| 数值/物理基准 | 已验证渗流基准、关键断面网格检查、必要的独立软件对照；有条件增加物理模型试验 | 渗流输入可信度及控制场景响应，不自动验证真实险情等级 |
| 独立工程记录 | 实测监测、现场复核、历史险情及处置前后记录、独立评定 | 工程状态区分、低估与误报表现、动态响应 |

参考等级优先由独立工程记录和未看到模型预测的复核人员确定，记录分歧和依据。即使使用专家参考等级，也应报告它是参考评定，不包装成无误差真值。用于反演参数的监测时段不能同时作为独立验证时段；用于输入的巡检图像不能单独再次充当融合方法的外部真值。

### 7.2 对照与消融

| 编号 | 方法 | 比较目的 |
|---|---|---|
| B0 | 适用渗流物理阈值/验算规则 | 工程物理基准 |
| B1 | 传统固定权重或AHP模糊综合评价 | 常规多指标基准 |
| B2 | 同样输入、组合权重与量化规则的静态加权模型 | 隔离关键约束和动态证据处理的增益 |
| P | 推荐模型：模式组织＋关键条件约束＋巡检证据＋不确定性 | 总体效果 |
| A1 | P去掉物理下限约束 | 验证是否避免关键危险被平均 |
| A2 | P去掉巡检证据 | 验证现场观测的增量价值 |
| A3 | P去掉质量/时效处理 | 检验过期、误检、缺测情形 |
| A4 | 固定单一参数结果与不确定性结果对照 | 检验结论稳定性表达，不预设分类精度必然提高 |

PPT原五模式模型可在取得完整代码和数据后做附加对照；主对照要统一为渗流范围，避免以任务范围不同制造优势。

### 7.3 情景设计

候选情景包括常见地层结构、薄覆盖层、透水夹层/局部接触带；正常、高水位及其他有工程依据的稳态工况；确认异常、疑似热异常、有效巡检无异常、未覆盖/过期；模型与观测一致、观测异常而计算未超限、计算裕度不足而表面未见异常。

先挑选12—20个具有明确预期行为的代表情景验证实现，再扩大为分层试验。情景数量是开发预算，不是独立工程样本量。仅在具备适用瞬态求解条件时追加涨水、长历时高水位和退水过程。

### 7.4 指标与数据划分

- 主指标：危险状态被低估的比例，并区分跨一级和跨多级低估；同时报告高危险等级召回率。
- 同时报告误报率/精确率及固定误报水平下的召回率，防止通过一律判高风险取得表面优势。
- 补充：混淆矩阵、宏平均F1、平衡准确率、有序等级误差；样本少时公开每类样本数和案例判定。
- 位置：匹配容差由定位误差决定，报告异常事件/区域定位效果，不能靠放大风险区取得高覆盖率。
- 时间：报告证据到评价更新的延迟；只有存在独立险情起始记录时才报告预警提前量。计算处理耗时与业务提前量分开。
- 不确定性：等级稳定性、关键变量扰动下翻转比例、区间或情景范围，以及参考状态的对应关系。没有真实概率标签时不强行报告概率校准指标。
- 可追溯性：抽取具体评价记录，核验其来源数据、计算值、触发规则和历史版本是否完整，记录缺失项。
- 划分：开发、校准与最终测试按独立堤段、洪水事件或巡检批次分组。避免同一事件连续帧、同一地质实现的近邻变体、同一洪水过程相邻时刻跨集合泄漏。
- 有足够独立组时，以工程单元/事件为单位做配对比较和分组重采样区间；组数不足时以描述性结果和逐例分析为主，不用大量帧数制造统计精度。

### 7.5 数据不足时的路径

A路径：地质、渗流和巡检能同段同时对齐，且有独立复核，完成工程验证型小论文。

B路径：只有地质/计算和部分现场资料，完成物理约束的评价方法与可获得案例验证，明确现场融合证据边界，不声称稳定的预警能力。

C路径：只有现有论文和合成数据，先完成方法原型、公式及验证设计；可写引言和方法工作稿，结果部分保留待补证据，不能将合成验证升级为工程应用结论。

### 8.1 建议职责

- 用户：研究问题、指标/模型设计、对照与消融、论文写作和第6章汇总。
- 地质模块负责人：原始地勘、模型版本、地层/参数提取与误差范围。

### 8.2 第一个工作周的具体动作

1. 获取透明评价PPT的875条合成样本、生成脚本、等级规则、权重矩阵和完整公式。
2. 选定共同案例，优先核查匿名堤段数据，并取得一条从钻孔到计算再到巡检的完整记录。
3. 确定一个评价单元的全流程输入输出，避免各模块各用一个工程却声称完成融合。
4. 取得规范全文，逐条建立分项结论/阈值映射；将自设分级与规范结论分开。
5. 核查可作为独立验证的现场记录，冻结开发与测试分组原则。
6. 输出研究问题—创新候选—验证证据矩阵，决定是否需要新增现场或物理试验。

| 统一术语 | 使用含义 |
|---|---|
| 渗流安全评价 | 本篇研究范围，不自动覆盖工程整体安全 |
| 巡检异常 | 图像/热成像等发现的疑似信息 |
| 现场确认险情 | 有独立现场复核支持的状态，与巡检异常区分 |
| 评价指数 | 模型内部可比较响应，不等同失事概率 |
| 模式内贡献 | 指标在特定公式内的数值贡献，不自动证明因果 |
| 动态评价 | 新证据或工况到来后更新结论，不自动意味着非稳态求解 |
| 透明评价 | 来源、规则、解释和更新过程可追溯 |
| 数字孪生验证 | 需要虚实数据关联与更新证据；纯场景截图仅是展示 |
