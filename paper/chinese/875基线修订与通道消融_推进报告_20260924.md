# 875基线修订与通道消融：推进报告

日期：2026年9月24日。对应第6章“融合地质、渗流场与巡检病害信息的堤防渗流安全透明评价”。

## 本轮完成内容

1. 将原生成程序、两份评价程序和关联矩阵保存为带指纹的参考快照，原资料包保持原样。

## 2. 缺测行为已经在哪个入口修正

新增`transparent_eval.legacy_guard.evaluate_guarded`。完整输入继续使用冻结模型；不完整输入在进入旧计算前停止，并返回：

```json
{
  "status": "insufficient_or_invalid_input",
  "result": null,
  "safety_score": null,
  "safety_grade": null,
  "engineering_validated": false
}
```

实际返回还含字段级`issues`、修订号和快照号。

|检查|修订入口行为|
|---|---|
|堤基/堤身/接触梯度缺字段或为null|拒绝以0代填，不给分级|
|梯度明确为0|与缺失区分，允许按历史规则评价|
|NaN、无穷、布尔数值、非法负梯度|返回输入问题，不静默计算|
|控制层参数缺失或导致非正临界梯度|不使用默认土层生成确定结果|
|沉降缺失|不默认为满分|
|管理或其他必需定性项缺失|不通过重归一化产生完整结果|
|没有匹配的地质或建筑物记录|不假定正常|
|巡检信息缺失|不解释为无异常|
|数值评分超出0—100|不静默截断|
|明确“不涉及”的模式条件|要求另行配置适用机制，不以100分保留五模式|

该入口是**完整875输入结构的研究校验入口**。它采用保守的整体拒判策略，尚不是支持任意缺测的29指标区间模型。既有`core.py`具有区间与确认事件下限机制，但两个模型尚未完成工程指标合并。

旧资料包及快照里的历史函数保留了原行为，直接绕过新入口调用旧函数不会获得这些修正。README已指向新运行方式。

未改变历史允许值、80/40分界、临界比值、权重或UAV判据。`J_allow`未进入旧渗流路径的问题作为显式适用性限制保留，等待工程依据后另设新规则版本。

## 3. 显式C3/UAV通道对照结果

|变体|具体操作|一致样本数|一致率|最终等级改变数|分数改变数|
|---|---|---:|---:|---:|---:|
|完整模型|原C3与UAV门控均保留|739/875|84.46%|—|—|
|关闭UAV门控|只取消最终UAV类别限制|739/875|84.46%|0|0|
|C3中性化|将C3设为无异常参考分100，权重保持固定|739/875|84.46%|0|150|
|两项同时处理|同时执行前两种通道操作|739/875|84.46%|0|150|

四组最终混淆矩阵均为：

|预设\预测|A|B|C|
|---|---:|---:|---:|
|A|296|54|0|
|B|25|150|0|
|C|0|57|293|

各组相对于预设C的低估均为57/350＝16.29%，预设非C判为C为0/525。这些是合成参考标签上的描述量，未计算独立工程置信区间或显著性。

解释边界：

- C3中性化是固定权重下的明确干预，不是缺测处理，也不是删除指标后重归一化。
- 其他指标如C6、历史险情仍可能编码观测信息，因此“两项同时处理”不等于移除模型中的全部巡检或现场信息。
- 结果说明该875集合没有体现这两个显式通道对最终等级的增量，不能据此证明通道对真实工程无用。
- 生成输入与参考标签共同依赖严重程度，物理与观测证据高度同步；现有集合不足以区分互补和冲突情形。

## 4. 边界与冲突诊断

额外构造一个低物理响应断面，同时赋予高等级UAV证据：完整模型和仅C3中性化均为C；关闭UAV门控后为A。该例确认门控通道确实接通，不能作为现场正确性证据。

缺失堤身梯度、接触梯度、控制层Gs、沉降值的诊断均返回证据不足。69项测试还覆盖空巡检、缺失地质/建筑物记录、参数域、评分范围、真正的0值与缺失区别、调用不污染原模型、快照篡改检测。

允许梯度分别取0.05、0.25、1.0，旧路径得分仍为86.1249、等级A。此次没有为使结果变化而选择新的物理阈值。

## 5. 第6章映射已经明确的边界

见《第6章指标_数据_判据映射_V1.md》及`research/configs/chapter6_indicator_mapping_v1.json`。

- C1/C4需确认取值位置、方向和允许值，才能进入实际渗流验算；不能按旧指标名直接改名为原型指标。
- C5接触冲刷不能代替盖层抗隆起，`uplift_demand_ratio`所需证据仍缺。
- C2排水有效性不能代替反滤状态，`filter_deficiency`需要独立定义及资料。
- C3从密度分数转为事件证据，需要真实定位、采集/入库时间、复核及覆盖；不能补造这些字段。
- A类多作为地质、结构或缺陷依据；D类按本章范围选择；E类用于证据质量和处置记录，不直接增加土体抗力。
- 旧A/B/C、原型G0—G3和正式规范评价等级保持分开。

因此，本轮完成的是完整映射登记，不是875条到新原型的虚构全字段转换。

## 6. 可写入论文的阶段性结果

在固定随机种子的875组合成情景中，冻结模型与严格输入校验入口对完整样本产生一致输出，与预设等级的一致率为84.46%。分别关闭最终UAV门控、将C3替换为无异常锚点以及同时执行两项操作后，最终等级均未改变；C3操作影响150组样本的评分，但未改变其最终类别。这表明该情景集可用于验证程序复现性及输入处理，却尚不足以证明显式巡检通道对安全分级的增量。构造的物理与观测冲突例证实门控可影响分类，其工程有效性仍需同段同工况的独立现场记录检验。

上述段落适合放在“合成实现验证”部分，不应改写为现场准确率或巡检有效性已获得验证。
