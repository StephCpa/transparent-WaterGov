# 巡检事件时空关联规范 V1

日期：2026年9月21日。研究原型已实现线性桩号范围与工况有效窗的候选关联，未实现无人机影像地理定位、自动跨帧跟踪或真实工程匹配精度验证。

## 输入与输出

实现：`research/transparent_eval/association.py`中的`associate(events, units, contexts, as_of)`。

| 输入对象 | 必需内容 |
|---|---|
| 事件观测记录 | event_id、reference_id、geometry_version、chainage_m两端点、observed_at、received_at、source_ref |
| 评价单元 | unit_id、reference_id、geometry_version、chainage_m两端点 |
| 计算工况适用记录 | context_id、unit_id、model_version、valid_from、valid_to、available_at、basis_ref |
| 快照 | 带时区的as_of |

桩号以米计，必须已经投影到同一条有版本的堤轴参考线；不能直接把经纬度填入。位置区间可包含病害范围与定位误差，形成方法须另行记录。没有误差估计时，不应为了得到唯一匹配而填写零宽度区间。

输出每个事件一条记录，列出候选单元与候选工况、来源及状态。不按候选数量复制成多个独立险情，也不为候选分配虚构概率。

## 判定规则

1. 空间范围采用闭区间求交。恰在两个相邻单元边界的点同时关联两者，保留边界歧义。
2. 仅与一个单元相交，但位置区间部分超出其边界时，仍标记空间歧义；没有观测依据支持把区间外部分忽略。
3. 工况有效窗采用左闭右开，避免相邻时间窗在同一时刻重复命中。有效窗须由计算负责人依据荷载变化及模型适用条件提供，代码不按时间接近程度代替水位匹配。
4. 同时检查采集、入库和计算结果可获得时间。历史快照只使用截至该时刻已获得的数据。迟到记录在之后的快照出现，不回写成过去已知。
5. 同一不可变event_id的完全相同记录去重；同ID但字段冲突拒绝。复核、确认、修订、解除采用新记录ID，并由上游另存关联关系；不能覆盖旧观测位置。
6. 多个计算版本同时适用时保留工况歧义，不能以列表顺序选一个。几何版本不一致时不自动转用最近版本。

状态包括unique_candidate、spatial_ambiguity、context_ambiguity、no_available_context、outside_units和reference_mismatch。唯一候选只表示给定输入下唯一，不意味着确认病害、验证水力联系或已完成地理配准。

## 与评价核心衔接

候选模块不自动注入事件；评价核心现已增加spatial_certainty维度，取definite或possible。为兼容原有已完成配准的输入，省略该字段表示definite；新候选关联输入必须显式填写，不能将歧义记录按旧格式直接接入。possible还须提供association_ref。事件kind仍独立表示suspected/confirmed/resolved，不以位置不确定为由修改现场观测的确认事实。

实际接入时应分别保存：观测是否确认、空间归属是否确定、适用失效模式是否明确。confirmed且possible的记录只提高该单元可能等级上界，标记证据不足；confirmed且definite才能施加确定下限。若另有独立确定险情，其下限继续有效。事件持续性与显式解除仍由评价核心处理，不使用工况有效窗使已确认险情自动消失。空间归属不确定的解除记录被拒绝，不能据此清除局部风险。

`association_experiments.py`已演示同一事件候选关联到两个单元后分别形成possible视图并参与评价。各视图保留同一event_id/evidence_id，统计时仍为一个观测；联合状态的不确定性不能用单元独立假设处理。一般化数据接入以及现场复核后重新定位的不可变记录流程尚未实现，不能以“解除病害”替代“纠正位置”。

调用方还须提供当时可获得的单元几何清单。当前函数检查版本一致性，但不管理几何版本的发布时间；离线快照不能传入事后修订几何而声称复现了当时判断。

## 已验证与待验证

候选关联10项单元测试覆盖边界点、跨界区间、部分出界、重复ID、迟到事件、时区等价、迟到计算结果、相邻/重叠工况窗以及版本不一致。新增4项核心检查验证空间归属对确定/可能约束、证据充分性、持续性及解除的影响；当前全套55项通过。两快照回放另有预期输出断言。这些是实现行为检查，不能作为工程定位准确率。

真实数据到位后，抽取人工核对的事件—单元关系，报告唯一匹配正确率、候选覆盖率、平均候选数量、未匹配率和歧义率，并列位置误差及场景类型。不能只靠扩大定位区间提高候选覆盖率。跨帧事件归并需使用独立标注评估过度合并与重复保留，当前仅有ID去重，不声称完成该功能。
