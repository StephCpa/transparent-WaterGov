# 透明评价小论文：组内数据需求与交付说明

日期：2026年9月21日。用途：融合地质、渗流计算与巡检信息，开展堤防渗流安全评价及独立工程验证。

## 可直接转发给负责人的说明

我们准备先完成一篇“融合渗流机理与巡检证据的堤防渗流安全透明评价”中文小论文，再并入大论文第6章。目前已梳理组内地质建模、渗流计算、P2ES-YOLO识别和透明评价汇报，正在完成评价算法与验证流程。

第一批希望取得同一工程、同一堤段能对应起来的一套基础资料，优先考虑匿名堤段；如果其他堤段的数据更完整，也可调整。无需先把所有数据整理成新格式，可以先提供原有表格、模型、程序及使用说明，我们负责转换。

最优先需要以下三组：

1. “透明评价-田昊琪”PPT对应的原始指标表、875条合成样本、样本生成程序、参考等级生成规则、评价代码和权重/关联矩阵。用于复现前期结果，并区分合成测试与真实工程验证。
2. 一个共同堤段的原始地勘、至少一个可复算断面、对应水位工况及完整渗流结果；请注明各论文使用的桩号、坐标和版本是否一致。
3. 该堤段带时间和位置的巡检资料，以及可用于独立验证的现场复核、渗压/水位监测、历史险情和处置记录。既需要异常案例，也需要有有效巡检覆盖的无异常案例。

如果目前没有同段同时间的巡检资料，请说明哪些资料已具备、哪些可以补采；我们会据此安排验证范围。仅有图像但没有定位，或只有检测图而没有原始输出，也请先提供现有材料和实际限制。

## 最小可用数据包

优先交付一个可追溯单元，再批量扩展。建议包含：

```text
工程简称/
  00_说明/       工程范围、桩号、坐标/高程基准、单位、版本、联系人
  01_地质/       钻孔表、剖面、土层参数、模型
  02_计算/       程序、输入、网格、边界、输出、对应工况
  03_巡检/       原图/视频、检测输出、轨迹、标注、覆盖范围
  04_现场复核/   复核记录、事件过程、监测和处置记录
  05_水位/       上下游水位过程及时间定义
```

原生Excel、CSV、JSON、VTK、软件工程文件均可。首批不要求各组先改格式；请保留字段说明、单位和能打开文件的软件版本。不要仅交截图或论文中的最大值统计，因为无法从这些信息可靠重建局部梯度及病害关联。

## 推荐字段与用途

| 记录 | 最小字段 | 单位/说明 |
|---|---|---|
| 工程单元 | project_id、unit_id、起止桩号、断面ID、geometry、crs、vertical_datum | 若无GIS文件，可先提供带定位说明的工程平面图 |
| 钻孔分层 | borehole_id、x/y、孔口高程、层顶/层底、soil_id、原始记录编号 | m；原始观测与虚拟钻孔分开 |
| 土层属性 | soil_id、Kx/Kz、参数来源、试验位置、范围 | m/s；若原文cm/s请保留单位，不先凭经验换算 |
| 工况 | case_id、model_version、水位、边界类型、稳态/非稳态标记、有效时间 | m、ISO时间；区分总水头和压力水头 |
| 场结果 | node/element_id、坐标、土层、水头、孔压、梯度分量/模、边界标签 | 水头m、孔压kPa、梯度无量纲；说明节点值/单元值 |
| 巡检事件 | event_id、flight_id、采集时间、位置及误差、检测类别、置信度、原图索引 | 检测框坐标需注明像素/归一化；不将框面积当真实面积 |
| 巡检覆盖 | flight_id、覆盖范围、时间、有效观测条件、漏拍区 | 无异常记录必须对应有效覆盖，不能以没有文件代替 |
| 现场复核 | review_id、关联事件、位置、时间、观测事实、判断依据、复核者角色 | 原始事实与判断分别保留；允许“不能确定” |
| 事件解除 | resolution_id、被解除事件ID、复核时间、消除依据、工程变化 | 已处置不自动等于已解除，需记录依据 |
| 水位/监测 | station_id、位置、时间、值、单位、仪器/人工标识、质量标识 | 保留缺测，勿填0替代 |
| 参考等级 | reference_id、sample_id、等级/事件状态、评定依据、独立性说明 | 不使用本研究公式自行生成的等级充当现场真值 |

时间尽量附时区（例如2026-09-21T10:00:00+08:00）。若只有日期或人工时间段，保留实际精度；不要人为补出秒级准确度。区分“发生/采集时间”和“研究者实际获得该记录的时间”，以便进行无未来信息的回放。

## 哪些资料暂时没有也能推进

| 缺少项目 | 可先开展 | 尚不能支持的结论 |
|---|---|---|
| 实时平台 | 离线评价、接口样例、回放文件 | 在线性能与实时平台验证 |
| 非稳态求解器 | 多稳态工况比较 | 洪水过程滞后、真实预警提前量 |
| 原始热辐射温度 | 目标检测事件关联、人工复核 | 绝对温差指标与热物理反演 |
| 分割掩膜 | 检测位置、事件持续性 | 精确病害面积与增长率 |
| 足够真实险情样本 | 实现验证、逐例工程分析 | 稳定的泛化准确率、可靠失事概率 |
| 独立参考记录 | 方法与数据组织 | 对真实安全状态的独立有效性验证 |

## 数据到位后的验收顺序

1. 先确认同一工程与空间范围；再统一坐标、高程和单位。
2. 对一个断面复算或核对输出，检查总水头、压力水头及孔压关系。
3. 对一个巡检事件核查原图、位置、工况和复核记录。
4. 确认开发、校准和独立测试的分组，随后再扩充样本。
5. 更新论文可以支持的结论范围和试验计划。
