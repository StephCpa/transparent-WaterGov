# 三、对照试验（新增5.4.3.5节）

**做法**

- 用原生成程序重新生成原批875条和另外5批记录，14项特征和规则等级与已发布的数据逐条一致。
- 把穿堤建筑物四项指标A3、B4、C6、D4的得分作为第15～18项特征加入随机森林。
- 采用两种划分方式，每种都分加与不加物理下限两种情况：
  - 分组划分，与原文一致；
  - 按记录分层划分，作为乐观上限。

**结果**（括号外为原批，括号内为另外5批均值）

| 特征 | 划分 | 物理下限 | 准确率 | C判A |
|---|---|---|---|---|
| 14项 | 分组 | 无 | 0.873（0.875） | 50（50.6） |
| 14项 | 分组 | 有 | 0.926（0.921） | 0 |
| 18项 | 分组 | 无 | 0.850（0.848） | 50（52.8） |
| 18项 | 分组 | 有 | 0.903（0.904） | 0 |
| 18项 | 按记录 | 无 | 0.945（0.932） | 0（8.8，范围0～15） |
| 18项 | 按记录 | 有 | 0.909（0.901） | 0 |

**结论**

- 分组划分下，即使加入建筑物特征，随机森林也识别不出穿堤建筑物情景的C级。原因是训练集中没有“物理量正常而建筑物失效”的组合。
- 只有在特征完整、且训练中见过该情景时，随机森林才能识别。这时加物理下限反而使准确率降低约3个百分点，但仍保证各批都没有C判A。
- 因此正文把物理下限定位为安全约束，而不是精度增强手段。这一认识已写入5.4.3.5节和5.6节第（3）点。

代码与结果：`experiments/analysis/paper_revision/structure_feature_control.py`（及同名.json/.csv）。
