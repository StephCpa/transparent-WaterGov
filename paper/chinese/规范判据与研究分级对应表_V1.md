# 规范判据与研究分级对应表 V1

核验日期：2026年9月21日。本文件是研究决策记录，不是工程安全鉴定报告。当前不建立研究四级与规范A/B/C的自动换算关系。

## 1. 本轮取得的直接证据

已从浙江政府公开附件下载《浙江省江河堤防安全评价技术导则（试行）》（封面2024年9月），全文33页。核对第1、7、9章，渗流分级跨页内容另经图像检查：印刷页24—25，对应PDF第28—29页。原PDF及文本保存在“规范来源”目录。

[官方全文](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3028/site/attach/0/5248adbe41e542bab857450de87abd02.pdf)

关键摘述：§1.2限定工程范围并排除圩堤等类型；§9.3综合现场、设施和计算证据，特定不利条件可触发C级；§9.7另定工程综合类别。因此，分项等级与整体安全类别不是同一输出。这是浙江地方文件，不能直接作为某省案例的适用规则。

SL/Z 679-2015的全国标准信息页面此前已核对，本轮没有取得并逐页核对其原文。地方文件引用该标准不等于已核实国家文件全部条款。四川官方隐患指引的SY-F002提供交叉检索线索，目前仅查看官方搜索摘录，不升级为全文已读。

## 2. 对研究方向的实质影响

以下为本研究基于上述证据作出的判断，不是导则原文：

1. 不再把“综合计算与现场资料”或“关键条件不可补偿”单独作为新方法的创新。它们应被视为合理工程评价的基线要求。
2. 方法贡献需落在可复核的增量上：异构证据如何关联到同一单元，迟到/重复/过期信息如何改变可用证据，缺失及参数范围如何影响结论，以及这些处理在独立工程记录中是否减少低估或误报。
3. 匿名堤段的工程名称不能替代正式工程分类。取得工程基础资料后，明确其所属工程类型及适用文件；本轮地方导则只用作方法比较，暂不进入工程自动判级配置。
4. 已有研究原型的四级标签、分界值和确认事件下限都是示例规则。原型通过实现测试不构成规范符合性证明。

## 3. 三类输出分开管理

| 输出 | 定义和证据 | 当前实现要求 | 禁止的推断 |
|---|---|---|---|
| 物理分项验算 | 明确机制、工况、作用与允许值的比较 | 保留原始物理量、参数范围、公式及来源；输出满足/不满足/待定/不适用 | 一个指标满足即推定全部渗流机制安全 |
| 研究动态状态 | 本文定义并校准的有序响应，用于证据融合和更新 | 当前称G0—G3或等级区间，注明规则版本；另列证据充分性 | 用数值0—3直接换算规范A/B/C，或称为失事概率 |
| 正式规范评价结论 | 适用标准、规定工况及专业评价程序下的结论 | 作为有来源的外部记录保存；没有符合条件的记录时保持未评定 | 将研究状态或平台颜色自动写成一/二/三类堤 |

同一研究状态可能对应不同规范结论，原因包括评价时刻、规定荷载工况、设施证据和空间范围不同。比较前必须先确认任务一致。

## 4. 工程规则登记表

每项准备投入工程评价的规则，应补齐下列信息。尚无来源的值保持空缺；不从示例配置抄入。

| 字段 | 填写内容 |
|---|---|
| rule_id / version | 唯一规则编号与版本 |
| source_title / edition / clause / page | 原始依据、版本、条文和页码 |
| jurisdiction / engineering_type | 地域与工程类型，是否适用于本案例 |
| mechanism / applicable_condition | 失效机制、土类、边界和工况条件 |
| raw_quantity / unit / extraction_region | 被比较物理量、单位、取值部位与方式 |
| limit / uncertainty_basis | 允许值、范围或试验依据，不重复施加已包含的安全系数 |
| evidence_ids / timestamps | 输入记录、采集和可获得时间 |
| physical_result / research_effect | 物理验算结论及对研究等级的影响，分别记录 |
| review_status | 条文适用性与工程参数核对状态 |

## 5. 验证协议调整

原B0单一物理验算仍保留，用于隔离巡检增量。另增加B-rule：由适用工程规则构成的计算—现场—设施联合判断基准。取得本案例适用规则后才能实例化，不能将浙江规则直接部署到某省工程。

B-rule与完整模型使用同一时刻可用资料，正确保留关键不利条件；不得把正常工程判级故意改成可被平均抵消的加权和。完整方法相对该基准的比较重点是低估、误报、拒判负担、证据关联错误及更新可追溯性。

若正式参考标签为A/B/C，而方法输出G0—G3，应另建有工程含义、测试前固定的共同终点，例如“是否存在经独立复核的目标渗流异常”。未经依据确认，不用任意数值映射计算四级混淆矩阵。共同终点只覆盖该目标，不能替代完整安全评价。

## 6. 尚需补齐

- 国家标准及本案例适用地方文件原文和具体有效版本。
- 工程类型、设计等级、规定验算工况、设施调查与历史安全评定。
- 出逸梯度、盖层验算等允许值和参数的工程依据。
- B-rule的完整规则及独立标签来源。
